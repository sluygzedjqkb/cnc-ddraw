## 🕹️ Overview

cnc-ddraw is a DirectDraw replacement DLL for Command & Conquer, Red Alert, and other classic DOS/Windows games, adding windowed mode, scaling, and shaders.

Whether you're a newcomer or a veteran, cnc-ddraw provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Windowed Mode** | Run any DirectDraw game in a window at any size |
| **Upscaling** | Integer and linear scaling up to any monitor resolution |
| **Shader Support** | CRT and pixel-art shaders via libretro shader format |
| **Wide Compatibility** | Works with C&C, RA1, RA2, Tiberian Sun, and many more |
